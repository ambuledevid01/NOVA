User Operating Manual & System Guide

1. Voice Command Control Module

How it Operates: Renders your speech live on screen in real-time as you speak (`interimResults = true`) and executes matched system actions immediately via Python automation. Speak naturally into your mic.

2. Eye-Movement Mouse Control Module

How it Operates: Uses webcam MediaPipe Iris pupil gaze tracking to map your eye gaze direction directly to screen resolution coordinates. Clicks are triggered by natural eye blinks.

FunctionOperation & GestureDescription
Cursor Gaze towards screen area Shifts mouse cursor position smoothly based on pupil center direction.
Left Click Single Deliberate Blink (~0.3s) Performs a standard left-click action at current cursor coordinates.
Edge Drift Gaze near screen borders Drifts cursor smoothly towards screen edge when looking far left/right.
Auto Safety Leave webcam frame (>3 sec) Safety auto-stop disengages mouse pointer when face leaves camera.
✋

3. Hand Gesture Control Module

How it Operates: Tracks 21 3D hand landmarks in your webcam feed. Adjust pointer gain and smoothing sliders on the Hand Control page to customize cursor speed.

GestureAction PerformedDescription
Pointer Index Finger Pointing Moves mouse pointer across desktop in real-time
Left Click Index + Thumb Pinch Executes Left Click or Hold & Drag objects
Right Click Ring Finger + Thumb Pinch Executes Right Click context menu
Scroll Pinky + Thumb Pinch (Slide Vertically) Scrolls active page Up or Down smoothly
👤

4. Head Movement Control Module

How it Operates: Tracks nose tip orientation and head pitch/yaw tilt relative to screen center.

Movement / GestureAction Performed
